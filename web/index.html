about

Probes on different networks test the same sites and publish every result to Arkiv, the Web3 database. This page has no backend. Your browser reads the chain directly, so taking this site down does not take the data down. Check it yourself.

networks

Each probe holds a heartbeat lease on Arkiv and renews it every round. If every probe in a region stops reporting, the leases expire and the region is marked dark: a possible shutdown.

evidence up to 7 days

Every DNS tampering or block page result. Entries are read-only, so nobody can edit them, including the probe that wrote them. When a probe on another network sees the same block, it extends the entry from 48 hours to 7 days.
