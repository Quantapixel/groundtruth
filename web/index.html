Volunteer probes on different networks test the same sites and publish every result to Arkiv, the Web3 database. This page has no backend: it reads the chain directly, so blocking or seizing a Groundtruth server cannot hide the data. Query it yourself ↓

Networks

Each probe holds a heartbeat lease on Arkiv that it renews every round. If a region's probes all go silent, their leases expire and the region goes dark: a suspected shutdown.
