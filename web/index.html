What is this?

When a website won't open in India, you usually can't tell why. The site might be down, your internet provider might be blocking it on a government order, or the internet in your area might have been shut off. Groundtruth tells these apart.

Small programs called probes run on different internet providers and try the same list of websites every minute. Each result is saved to Arkiv, a public database that nobody can edit or delete from, not even us. This page reads those results straight from Arkiv. There is no Groundtruth server, so blocking this website does not hide the results.

How to read the results

works
The website opened normally on every network.
blocked
At least one internet provider is interfering: it gave a fake address for the site, or showed a "this site has been blocked" page. Other providers can still reach it.
down everywhere
No network can reach it. The website itself is probably having an outage.
fails on some
Some providers can't connect while others can, but there is no clear sign of blocking.
slow on one
It works everywhere, but one provider is much slower than the rest.
silent
All the probes in a region stopped reporting at once. That can mean the internet there was switched off.

Networks

Every probe sends a "still here" signal to Arkiv with each round of results. The signal expires after 3 minutes unless it is renewed. If every probe in a region goes quiet, the region is marked silent.

Right now results from the last 30 minutes

Each row is a website. Each column is an internet provider. Click any result to see the raw record on Arkiv.

Evidence of blocking kept for up to 7 days

Every time a probe caught a provider blocking a site. These records are locked, so nobody can change them later, including the probe that wrote them. Normally they expire after 48 hours. If a probe on a different provider sees the same block, it extends the record to 7 days.

Using this as evidence? Click any record to see exactly what the probe saw and a permanent record ID. Anyone can look that ID up on the public Arkiv explorer, so you can cite it without relying on this website. Records from networks marked "lab" are simulated for demos, not real internet providers.
